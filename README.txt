# Peer-graded Assignment: Prediction Assignment Writeup

This project is part of the Coursera course [Practical Machine Learning](https://www.coursera.org/learn/practical-machine-learning). The goal is to use data from accelerometers to predict the manner in which participants performed barbell lifts.

## 📂 Files Included

- `MachineLearningAssignment.Rmd`: The R Markdown file containing code, analysis, and explanation.
- `MachineLearningAssignment.html`: The compiled HTML report generated from the Rmd file.

## 🌐 View the Report Online

The compiled HTML report can be viewed via GitHub Pages at:

[https://roosvanderkroon.github.io/Peer-graded-Assignment-Prediction-Assignment-Writeup/MachineLearningAssignment.html](https://roosvanderkroon.github.io/Peer-graded-Assignment-Prediction-Assignment-Writeup/MachineLearningAssignment.html)

## 🧠 Summary

The model was trained using the Random Forest algorithm with 10-fold cross-validation. The model achieved a high accuracy on the validation set, and predictions were made on the final 20 test cases.
